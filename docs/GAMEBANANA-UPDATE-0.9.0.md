# GameBanana update 0.9.0

GameBanana has no public write API: uploading a file or editing a submission goes through the website while logged
in. This is the material used for the 0.9.0 update.

## 1. Update: title and text

**Update name**

```
0.9.0 - button remap, Armory, new HUD layouts, Rekarina & SHB-OcarinaTweaks
```

**Update description**

```
0.9.0 adds a full button remap (every button gets the role you choose, including L3 / R3, a shield button and an
Armory to change sword and shield), two new HUD layouts with size sliders, enemy aggression options, Rekarina support
and the Switch GameCube preset. The app is now called SHB-OcarinaTweaks.

IMPORTANT - REBUILD ONCE
The module changed: reinstall the profile (emulator) or rebuild the game once with 0.9.0 (Longshot / Hookshot / ReLink / Rekarina).

CONTROLS
- Button remap for L, R, ZL, ZR, X, Y, A, B, L3 and R3, with a remap editor and five control presets. A remapped button
  only does its role while you play; menus, dialogues and shops keep the real buttons.
- Armory: hold its button to open the item drawer with your swords and shields. A Shield role shows the equipped shield.
- Quick mask returns from the Lens of Truth to the last mask. Item buttons: the ZR item follows Child / Adult, no more
  undone items under the pause menu. The L3 sprint works on Rekarina.

HUD
- Wide, Simple (soft bar) and Plain layouts, and size sliders for the controls cluster and the counters.
- Widescreen groups and the Switch GameCube preset (HaseoSora). The area counter counts world heart pieces.

DIFFICULTY
- Enemy aggression: alert radius and aggression level. Wall and ceiling enemies are no longer duplicated; enemy health is
  scaled exactly once. Recommended is now the author's own setup.

REKARINA AND APP
- Rekarina is supported as a target. The app is now SHB-OcarinaTweaks, with a new interface.
```
