SHB-OcarinaTweaks 0.10.0 - REBUILD ONCE
The module changed: reinstall the profile (emulator) or rebuild the game once with 0.10.0 (Longshot / Hookshot / ReLink / Rekarina). If a crash remains, attach logs/longshot_log.txt (or the Rekarina log) and the new file in bug-reports/.

SHB-OcarinaTweaks (Super Hero Boost) is a gameplay and HUD module for the Ocarina of Time remake (update v131072): stamina, difficulty, an extended HUD, a full button remap, item buttons, quick select and more. Everything is a switch in the companion app, SHB-OcarinaTweaks, and the installer patches the module with the profile you pick: no recompiling, no manual file editing.

WHAT YOU ARE DOWNLOADING
The file in the Files tab is SuperHeroBoost-0.10.0-presets.zip: the mod itself, with all 15 named profiles of the app ready to install in an emulator. It contains no executable. The configuration app is a separate download (see "Emulator - custom settings" below); it is not in the Files tab.

NEW IN 0.10.0 (everything since 0.9.3)
REBUILD ONCE
- The module changed (the configuration block grew): reinstall the profile or rebuild the game once.
CONTROLS
- A long press on L and R too: every button that can be held has a row now (A, B, X, Y, L, R and the D-pad right). A hold can be Jump, Sword, Action, Center camera or Back.
- Wait or no wait, per held button: with "Skip the tap action when held" the tap waits about a third of a second to know it is not a hold, and a hold never also fires it; off, the tap acts at once and the hold comes on top.
- The D-pad right is not a choice: its tap always calls Navi and the hold is the role you gave it, so its row shows a note instead of that switch.
- Shortcut roles may repeat: Jump, Sword, the item selector, the Armory and Back can sit on two buttons at once, and the Controls card lists the game's own actions that no button has.
- Back moved to the held X in the Triggers and Action at the bottom tables (the held B is the action or the item there).
- Button mapping off turns its whole card off, and the custom item HUD is its own option: off, your item HUD and the game's item logic are untouched.
HUD
- The corner minimap hides properly (it used to blank the map screen) and the interaction guide bar is hidden while the button-mapping HUD is on.
- The simple and plain rows pack from the left, each icon right before its number.
DIFFICULTY AND ENEMIES
- Enemy health and damage taken multipliers go up to x6: x1, x1.5, x2, x2.5, x3, x4, x5 and x6, the same ladder in both apps.
- Aggression options (alert radius, Normal / Aggressive / Maximum) combine with the enemy speed multipliers instead of replacing them.
MODULE
- Durations are real seconds now: the sprint drain, the action costs, the recharge and the 0.3 s hold last what they say whatever the frame rate.
- The module writes nothing into your save folder any more (the shbdebug.bin diagnostic exists only in test builds).
- The ZR button keeps its own item, an item used from a slot stays in hand, and the context prompt has a single writer.
APP
- The app is in Rust now: one executable, no Python, and it builds the game itself on Longshot / Hookshot / ReLink and Rekarina, with a progress bar and a Cancel. Linux and macOS downloads are built again.

NEW IN 0.9.3 (everything since 0.9.1)
CONTROLS
- Two actions on A, B, X and Y: every one of those buttons has a second row in Controls (a down arrow) for what it does when you HOLD it (about a third of a second). The short press acts at once, with no delay; when the hold fires, the short role lets go. It takes Jump, Sword, Action, Center camera, Sprint, Shield, Item selector, Armory or Back.
- New role Back: the game's own B (let go of a ledge, cancel, get off ...) on any button or in a hold. It is not an item use: it acts while Link is busy with something else (hanging, climbing, swimming ...) or when the B slot holds no item.
- Triggers and Action at the bottom now put Back on the held B (Recommended, Recommended (no beta enemies), Super Hero, Ultra Hero and Beta All bring it).
SPRINT (TOGGLE)
- The toggled sprint lets go by itself when you stop moving.
- It no longer throws the jar you lift (its A did): while you carry something it only gives the speed.
FIXES
- The manual shield threw lifted jars by itself: the module no longer touches the guard flags while Link carries something.
- Installing the PlayStation layout now also installs the font of the button glyphs: before, only the menu's controller picture changed and the rest of the game kept the Switch buttons.
- Heart pieces in chests count in the area counter (0.9.2): the ten chests with a heart piece are in the total, so an area whose only piece is a chest no longer reads 0/0.
- The app opens with the stamina system off (it crashed).

NEW IN 0.9.1 (everything since 0.9.0)
CONTROLS

- The item selector goes on any button but the sticks and no longer takes Item 2 away: both can be on the table at once.
- New control preset "Triggers": items on the triggers (R, ZL, ZR), the item selector on B, the shield on L, sprint on L3, target on R3. Recommended, Recommended (no beta enemies), Super Hero, Ultra Hero and Beta All bring it.
- Every profile with the pack's buttons (all but Manual Shield) puts the Armory on the held D-pad right. Sprint is x1.25 in every profile.
APP
- Sprint speed is back in the Gameplay page (the option had disappeared from the window).
- New drop-down lists: the wheel scrolls the list and never the page, a click outside only closes it, arrows and Enter work.
- Recompile (only runs the builder, copies nothing) and Reinstall and recompile for Longshot / Hookshot / ReLink / Rekarina, shown only while the mod is in the game.
REKARINA
- Merged mods: the other mods' ExeFS patches no longer make Rekarina's converter drop our hooks.
- PlayStation / Xbox prompts, the ocarina's note buttons included: the app no longer installs its own copy of the game's button font on Rekarina, which stopped Rekarina from switching the prompts.

NEW IN 0.9.0 (everything since 0.8.0)
CONTROLS
- Button remap: every button (L, R, ZL, ZR, X, Y, A, B, L3, R3) gets the role you choose: Jump, Sword, Action, Target, Item B / L / R, the game's own item, Center camera, Sprint, Shield, Item selector, Armory or nothing. The HUD, the pause menu legend and the assign buttons follow. The app has a remap editor with previews and five control presets (Classic, Action at the bottom, Manual shield, Souls, Switch GameCube).
- A remapped button only does its role while you play; menus, dialogues and shops keep the real buttons.
- Armory: hold a button with that role to open the game's item drawer with your swords and shields and equip one. A Shield role shows the equipped shield on the HUD.
- Quick mask returns from the Lens of Truth to the last mask you wore.
- Item buttons fixed: the ZR item follows Child / Adult, the Deku stick stays in hand, assigned items are not undone under the pause menu, and the L3 sprint toggle works on Rekarina.
HUD
- Three layouts: Wide (native plates), Simple (the four counters on a soft translucent bar) and Plain (the same row, no bar).
- Size sliders for the controls cluster and the counter row.
- Widescreen: the HUD groups move together with Longshot's "Screen's edges" setting (thanks HaseoSora). New Switch GameCube preset (HaseoSora).
- The area counter (Skulltulas and heart pieces) copies the save's key set and counts world heart pieces.
DIFFICULTY AND ENEMIES
- Enemy aggression: alert radius and an aggression level (Normal / Aggressive / Maximum). Bosses are not changed.
- Duplicated enemies: wall and ceiling enemies are no longer cloned.
- Enemy health is scaled exactly once.
- Recommended is now the author's own setup and the other profiles follow it.
REKARINA AND APP
- Rekarina is supported as a target (the app lifts and rebuilds with Rekarina's own tools; nothing in its folder is edited). Changing options afterwards takes seconds.
- The app is now called SHB-OcarinaTweaks, with a new interface (presets page, inline help, remap editor).

FEATURES
STAMINA
- Four styles: hardcore (every action costs), combat only, sprint only, or advanced (choose which actions cost). Exhaustion and regeneration, with individual costs for rolling, jumping, attacking, shooting, sprinting and blocking.
- A ring next to Link, or a segmented bar under the magic gauge (yellow, red while recharging).
DIFFICULTY
- Enemy health and damage taken multipliers (x1 to x6). No heart drops and no magic jar drops: they become green rupees.
- Configurable sprint speed (x1.25 in the profiles).
HUD
- Always-visible rupee counter and clock (off / 12 h / 24 h). Per-area Skulltula and heart-piece counter. Option to hide the corner minimap.
CONTROLS
- A second action on every button that can be held: A, B, X, Y, L, R and the D-pad right. The short press acts at once (off by default), the hold does its own role, and shortcut roles can sit on two buttons.
- B, L, R and ZR item buttons on the HUD with the quantity of consumables, assignable from the pause menu's Items tab.
- Switch, PlayStation and Xbox button styles; Nintendo, A/B swapped, Xbox and Switch GameCube positions; extended or simple layout. PlayStation and Xbox prompts download their archive once (~70 MB) from the GameBanana controller-UI mod; Switch needs nothing.
- Target with R3 (swaps ZL and R3), switch target, next target when the locked enemy dies, hold or toggle L3 to sprint, manual shield.
- Songbook autoplay: select a learned song in the native songbook (ZL) and Link plays it with its effect.
QUICK SELECT
- Hold D-pad Down for the Iron / Hover Boots; hold D-pad Up for the Lens of Truth / your mask.
WORLD CHANGES (optional)
- The three Great Fairy magic rewards are reordered. Farore's Wind warp points can be placed outdoors.
BETA (optional, experimental, off unless you turn them on)
- Enemy duplication, and enemy speed in four components (movement, animation, attack cadence, projectiles) from x0.5 to x6, with their own boss speed. They install extra romfs files and can break puzzles, quests or performance. Back up your save and test one at a time.

REQUIREMENTS
- The game on update v131072.
- An emulator that loads mods from its user/load folder, or a Longshot / Hookshot / ReLink / Rekarina installation.
- Back up your saves. On Windows the app closes a running game before installing and during a rebuild; save first.

EMULATOR - QUICK INSTALL (PRESETS ZIP)
1. Download SuperHeroBoost-0.10.0-presets.zip from the Files tab and extract it.
2. Open the folder of the profile you want (01 Recommended, 02 Recommended (no beta enemies), ...).
3. Copy its zz-Super-Hero-Boost folder into user/load/0400486024DEC000 (merge it if that folder already exists).
4. Start the game.
Only one profile can be installed at a time: they all use the same folder name, so replace the previous one.

EMULATOR - CUSTOM SETTINGS (APP)
1. Download SHB-OcarinaTweaks.exe from GitHub Releases: https://github.com/kuribox/OOT-SuperHeroBoostMod/releases/tag/v0.10.0 (the Rust app is built for Windows, Linux and macOS there; the Python app is published next to it as the -legacy files). The module is bundled inside the app: you do not need Python.
2. Save your progress. On Windows the app closes the game for you before installing.
3. Pick a profile or adjust each section: Gameplay, Difficulty, Controls, HUD.
4. Choose your emulator folder (the one that contains "user") and press Install.
5. Start the game. Settings only reach the game after pressing Install again.

LONGSHOT, HOOKSHOT, RELINK AND REKARINA (use the app)
The presets zip is for emulators only. Static recompilations ignore exefs mods, so the module has to be built into the game. Use the app from GitHub Releases: select the target, point it at your game folder, choose the profile and press Rebuild game. The first build takes 25-45 minutes on Longshot and 10-20 on Rekarina; later settings changes need no rebuild. Uninstall restores the original files.

IN GAME
- Item buttons: pause menu -> Items tab, highlight an item and press the button of its slot. The game's own ZR box still works with A.
- Armory: hold the Armory button (in the profiles: hold D-pad right), move with the stick or D-pad and let go to equip. A short press of D-pad right still calls Navi.
- Stamina: the ring (or bar) shows what is left; it refills when you stop.
- To remove the mod, press Uninstall in the app (or delete the zz-Super-Hero-Boost folder).

COMPATIBILITY
- Emulators: tested and working on lichii and Fritchii.
- Longshot: supported and tested. Hookshot: expected to work, not tested yet. ReLink: supported. Rekarina: supported (new in 0.9.0).
- Real hardware: not tested.
